# فاز ۹ تا ۱۷ — برای توضیح در مصاحبه

این بخش ادامه نسخه مرجع است. دموی `spring-boot:run` هنوز حافظه است. تست‌ها، از جمله Postgres وقتی داکر روشن است، شواهد فازهای بعدی‌اند.

## ۹ — حسابرسی و مصالحه
هر عمل مالی یک ردیف audit با actor و correlation id می‌گیرد. `audit_log` و `ledger_entries` در دیتابیس قابل ویرایش نیستند. `Reconciliation` اختلاف کش و تا شدن دفتر را گزارش می‌کند؛ یک اختلاف کاشته‌شده باید دیده شود. شناسه همبستگی با `CorrelationScope` به نخ دیگر می‌رسد. ویو `monthly_volume` گزارش است، نه جدول تراکنش.

اگر audit قابل ویرایش باشد، ممیز نمی‌تواند به آن تکیه کند. ردیف audit در این نسخه بعد از موفقیت نوشته می‌شود، نه برای عملی که rollback شده. مصالحه اختلاف داده واقعی را می‌بیند، نه فقط سناریوی تست. شناسه باید از مرز نخ رد شود وگرنه لاگ ناهمگام گم می‌شود. AOP برای تصمیم کسب‌وکار مناسب نیست چون آن تصمیم باید در کد سرویس خوانده شود.

## ۱۰ — کارمزد، بهره، سقف
`FeeCalculator` چهار نوع قاعده دارد و HALF_EVEN است. `Interest` سه شمارش روز دارد، از جمله ۲۹ فوریه ۲۰۲۴. `DailyLimit` با صد نخ همزمان از سقف رد نمی‌شود. هر نتیجه rule id و reason code دارد.

## ۱۱ — ISO و IBAN
زیرمجموعه آموزشی است، XSD رسمی ISO نیست. `CamtStatement` فایل معتبر را می‌خواند و فایل ناقص یا DOCTYPE را رد می‌کند. جمع یک صورت‌حساب ۱۰۰ مگابایتی بدون نگه داشتن همه ردیف‌ها انجام می‌شود. IBAN با mod 97 است. `GB82WEST12345698765432` معتبر است. وارد کردن دوباره همان شناسه صورت‌حساب هیچ پستی اضافه نمی‌کند. `pain.001` یک XML مطالعه است.

## ۱۲ — Outbox
رویداد POSTED در همان تراکنش JDBC نوشته می‌شود. اگر commit نشود، ردیف outbox هم نمی‌ماند. Relay دوباره تلاش می‌کند و بعد از حد، پیام به dead letter می‌رود. مصرف‌کننده با شناسه رویداد تکرار را نادیده می‌گیرد. ترتیب برای یک حساب حفظ می‌شود، بین حساب‌ها نه. کافکا در compose هست و تست معنایی بدون بروکر است. ADR 0010.

## ۱۳ — کیفیت
`mvn test` دروازه است. ArchUnit جلوی وابستگی دامنه به Spring و JPA را می‌گیرد. تست ویژگی برای کارمزد و دفتر سفارش هست. امتیاز mutation و بیست اجرای پیاپی CI در این نسخه وجود ندارد. این را نگو که داری.

## ۱۴ — مشاهده و بار
SLO در `docs/ops/SLO.md` است. هشدارها در `docs/ops/alerts.yml` با اقدام اول هر کدام. صدک‌های کارمزد در `LaterPhaseTest` اندازه‌گیری می‌شوند. داشبورد Grafana فقط یک JSON مطالعه است و سروری پشت آن نیست. استخر اتصال پر، خطای مشخص می‌دهد. ۵۰۰ انتقال همزمان روی Postgres شواهد بار است.

## ۱۵ — هوش مصنوعی خارج از مسیر پرداخت
اگر مدل خطا بدهد یا برچسب نامعتبر بدهد، دسته `OTHER` است. پرداخت به مدل وصل نیست. شماره حساب قبل از prompt ماسک می‌شود. بودجه و لاگ پرسش عامل و حد نرخ هست. مدل واقعی صدا زده نمی‌شود. ADR 0011.

## ۱۶ — تحویل
`Dockerfile` روی پروفایل local بالا می‌آید، بعد از `mvn -DskipTests package`. اسکریپت دمو `docs/demo/SCRIPT.md` است. ویدیو ضبط نشده. محدودیت‌ها در README و `docs/quality/GATES.md` هستند.

## ۱۷ — دفتر سفارش
`OrderBook` تک‌نخی، اولویت قیمت-زمان، پر شدن جزئی، و بدون دفتر crossed است. مقدار سفارش برابر معامله به‌علاوه مانده به‌علاوه لغو است. بازار پرنشده استراحت نمی‌کند. قطعیت از توان عملیاتی مهم‌تر است چون بازپخش باید همان معامله‌ها را بسازد. پشت یک معامله، یک بدهکار و یک بستانکار به مبلغ قیمت ضربدر مقدار است. ADR 0012.
